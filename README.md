# Agent Skills

这是一个已搬运实际内容的 Skills 仓库。当前已经把两个独立 skill 的源码与说明文件直接复制到 [skills](skills) 目录下，不再只是保留 GitHub 地址引用。

## 已搬运的 Skill

### 1. draw-ui

- 位置：[skills/draw-ui](skills/draw-ui)
- 作用：设计 App、后台、游戏界面和完整网站落地页，并在需要时将设计稿或截图还原为 HTML/CSS、现有前端项目或微信小程序页面。
- 适用场景：页面设计、UI 视觉构思、截图还原、落地页生成。

### 2. prompt-polishing

- 位置：[skills/prompt-polishing](skills/prompt-polishing)
- 作用：把简短、含糊或不规范的需求润色成更清晰、专业、适合编程助手直接理解的提示词。
- 适用场景：提示词优化、需求整理、任务描述重构。
