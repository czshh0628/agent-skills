# 图片测量与校准

视觉判断负责选区、主体、构图和字体层级；程序负责尺寸、坐标、颜色统计与图片偏差。此流程处理已有参考图和候选图，不采集页面或检查 DOM。浏览器截图也只作为普通图片输入，不代表已验证页面身份或交互。

## 选择验证范围

- 完整页面：记录参考图尺寸及已知的逻辑视口映射，测量关键区块并与完整候选图比较。
- 局部修改：只标注目标区域和必要的相邻锚点，可复用已核对的基线。
- 暂无候选图：仍可测量参考图并记录设计约束；图片对照保持未验证，不生成虚构的采集数据。

## 实现前建立基线

1. 选择少量关键锚点：区块起点、容器边距、重复网格、标题与素材容器。按原图像素填写区域清单；只在逻辑视口宽度已知时填写 CSS 映射。
2. 运行 `measure_reference.py`，打开标注图确认范围，再检查颜色与几何统计。选区不准先修清单；程序不会自动识别正确边界。
3. 从统计中选择少量公共变量和布局约束，将测量事实、推断和实现选择分开记录，再编写布局与样式。

测量时保留这些区别：

| 对象 | 判断方式 |
| --- | --- |
| 色面 | 在内部避开文字、摄影和高光；同时看中位数与分位数，波动大时检查渐变或污染，不把每个采样值变成 CSS 变量 |
| 重复组件 | 比较宽度与间距分布；小幅采样波动可归为公共规格，明显不同的比例应保留，不先假定等宽 |
| 文字 | 元素外框、文本行盒和可见字形分别判断；字形框不能靠缩短标题块宽度修复 |
| 装饰与素材 | 斜切边界与正文几何分开；图片按既定容器比例、主体位置和遮挡范围检查，规格冲突时回到素材流程 |

## 比较候选图片

1. 对齐参考图和候选图的像素尺寸；使用同一基线，不自动拉伸图片。
2. 运行 `compare_mockup.py` 生成局部差异和尺寸报告。长页确需高度不同时，显式允许高度差；工具只比较共同坐标并保留未匹配尾部。
3. 按目标显示尺寸目视复核，检查字形、素材、遮挡和页面完整性。像素差异用于定位问题，不转换成“还原度百分比”。

如果候选图来自浏览器，比较只处理这张图片的像素；它不验证 URL、视口、DPR、字体加载、DOM 几何或交互状态。

## 修正与复验

连续区块同向偏移时，先查最早发生偏移的位置；调整顺序为页面宽度与容器、字体与换行、间距、素材裁切与装饰，不给后续区块逐个打位移补丁。

每次比较使用新的输出目录。参考图或区域标注改变时重新测量建立基线；候选图改变时重新比较。摄影、近似字体和品牌原稿缺失造成的差异单独说明。最终结论依据局部画面、图片报告和项目已有功能测试；图片审阅不证明交互与响应式已经实现。
